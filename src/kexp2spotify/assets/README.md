`kexp-logo-black-on-orange.jpg` is a JPEG rasterization of the KEXP logo sourced from Wikimedia Commons:
https://commons.wikimedia.org/wiki/File:KEXP_logo_(black_on_orange).svg

The Commons file page identifies this simple logo as public domain under PD-textlogo and
notes that trademark restrictions may still apply. The image is bundled to avoid depending
on an external image fetch during playlist updates.
